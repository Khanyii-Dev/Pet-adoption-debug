# 🐾 Debug a Pet Adoption Page - FreeCodeCamp

### Skills Demonstrated
Debugging HTML semantic errors + accessibility fixes for Sally's Pet Adoption Store.

### Problems Fixed
1. **Image not displaying**: Changed `href` → `src` on `<img>` tag
2. **Missing accessibility**: Changed `att` → `alt` with descriptive text  
3. **Invalid HTML**: Removed `</img>` closing tag - `img` is a void element
4. **Broken navigation**: Changed `src` → `href` on both `<a>` tags

### Why This Matters
- **Accessibility**: `alt` text helps screen readers + SEO
- **Standards**: Void elements improve HTML validation scores  
- **User Experience**: Working links = users can actually adopt pets

### What I Learned
- Difference between `href` vs `src` attributes
- HTML5 void elements don't have closing tags
- Semantic HTML impacts both users + machines parsing data
